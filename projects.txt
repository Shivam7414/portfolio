Associated with Maxaix
SendMePls is the most technically challenging and complete project I’ve built. It’s a multi-service platform created in Laravel with full REST APIs and an admin system. The platform supports two user types-customer and delivery agent-and offers three core services: Parcel Delivery, Ride Booking, and AI-powered Shopping.

Parcel and Ride work similar to Uber: customers create requests, pricing is calculated, and nearby delivery agents receive and accept the job. The Shopping flow is more advanced-customers create a cart, select shops, add items, and the system generates an estimated price using an AI API. After payment, a delivery agent accepts the job, purchases items one by one, and delivers them to the customer.

To make this work reliably, I implemented a real-time system using queues, jobs, events, Redis, and WebSockets. The platform also includes live driver tracking and a high-performance architecture designed for continuous updates without delays.

Key Highlights:
• Built entire platform in Laravel with REST APIs
• Two user types: Customer & Delivery Agent
• Services: Parcel Delivery, Ride Booking, AI-powered Shopping
• Real-time location tracking (Redis + WebSocket events)
• Queue & Job system for stable, async task processing
• AI-based price estimation for shopping orders
• Delivery flow where agent purchases items in real time
• Full admin panel for managing users, categories, pricing, and requests
• Production-ready architecture designed for speed and reliability
